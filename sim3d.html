① 覆盖的交互模块

  • 三维场景漫游：外部俯视/驾驶室双视角，缩放·旋转·平移
  • 行走就位：驻车—挡位—油门—制动，限速与安全限位监控
  • 支腿调平：四支腿 + 左右调平，车身姿态实时联动
  • 三臂独立控制：3臂 × 5关节（俯仰/摆角/梁伸缩/梁俯仰/钻机进退）
  • 布孔与选孔：16孔三类标记，钻臂推荐与可达性判定
  • 对孔引导：三维径向/轴向偏差、方向提示、5cm就绪阈值
  • 防碰监测：臂-臂 / 臂-车身 / 臂-掌子面包围盒检测
  • 钻进流程：模式匹配、钎杆接杆、自动退钻、过程记录
  • 考核评分：四维雷达 + 数值明细 + JSON/截图导出
  • 演示引导：分步叙事、UI聚焦、工程意义注记

② 考核维度与评分逻辑

行驶 20%：驻车顺序(25) + 接近减速(25) + 停车位置(50)

停车 20%：支腿伸出(30) + 车身水平(40) + 作业距离(30)

定位 30%：对孔偏差(50) + 定位耗时(30) + 碰撞(20)

钻进 30%：就绪质量(25) + 模式匹配(25) + 过程洁净(25) + 效率(25)

全部依据数值化过程数据（cm / s / 次数）自动结算；阈值与权重集中于 scoringConfig，可现场适配赛项规程。

③ 可扩展方向

  • 接入真实 PLC / CAN 总线数据回放，构建数字孪生校核
  • 故障排查场景：卡钎、液压泄漏、断钎处置训练与评分
  • 多人协同：教练端下发任务 / 学员端作业，双端评分对比
  • VR / 手柄操作映射与力反馈，提升操作沉浸感
  • 爆破轮廓质量后评估（超欠挖统计）回灌评分体系
